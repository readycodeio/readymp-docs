With SDK version `0.2.1`, we're releasing a set of stability updates and bug fixes to improve the overall experience of using WukongMP SDK.

The accompanying launcher update (version `0.25.1`) now shows the option to connect to self-hosted servers for everyone.

This update is compatible with SDK version `0.2.0`, so you can update your server without needing to update your mods immediately. However, we still recommend updating your mods to take advantage of the latest improvements and fixes.

<!-- truncate -->

## Quality of life updates

* The PvP mod is now the default in the server package. The co-op mod is still included in the `optional_mods` folder. You can swap them by moving the desired mod to the main `mods` folder and removing the other one. Having both enabled will crash the game, so make sure to only have one of them enabled at a time.
* Banning someone in the admin panel now immediately kicks them out of the server.
* Added a `/kick` command to the admin panel, which allows you to kick a player without banning them.
* Both the Launcher and the mod now display appropriate messages when trying to connect to a server where the player is banned or not whitelisted.

## Bug fixes

* **[co-op]** Fixed an issue where getting far enough away from enemies would cause them to idle for other players.
* **[co-op]** Fixed an issue where bosses would become idle after teleporting away a significant distance and returning to the boss area.
* **[co-op]** Fixed synchronization issues around spider enemies in Chapter 4.
* **[PvP]** Choosing to "Start a new cycle" on an endgame character is no longer possible, as it causes spawning in a different area and falling under the map.

## What's next?

We continue to work on **server-side scripting** -- once that is ready, we'll remove the temporary PvP and Cheats APIs and implement their functionality inside the PvP mod itself.
