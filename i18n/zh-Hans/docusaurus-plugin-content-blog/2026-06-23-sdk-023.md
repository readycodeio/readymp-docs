随着本版本的 SDK，我们引入一个**public server list**功能。这使玩家能够轻松发现并连接到正在运行 WukongMP
的公开服务器。它还包括一些提升用户体验的改进和 SDK 的错误修复。

要充分利用这些功能，请确保将服务器二进制文件更新至版本 `0.2.3`。服务器列表仅在 ReadyM 启动器版本 `0.29.0`
或更高版本中可见，因此也请更新您的启动器。

新的 `0.2.3` 服务器和 SDK 应该与使用 `0.2.2` SDK 构建的模组兼容，但我们建议在新 SDK 上测试你的模组，以确保兼容性。

## 服务器列表

为了让您的服务器出现在 Launcher 的公开服务器列表中，您需要在配置文件中配置相关设置。有关如何配置您的服务器的更多信息，请参阅
[服务器列表文档](/wukong-mp/docs/Server/server-list) 页面。

## SDK 更新

本 SDK 版本的变更列表如下：

* 已在控制台中添加了 `help` 命令，该命令将列出所有可用命令。
* 现在，告知玩家已被断开连接的横幅将包含断开原因（如有）。
* 新增了
  [`IWukongConsoleApi.AddCommand`](../wukong-mp/api-reference/WukongMp.Sdk.Api/WukongMp.Sdk.Api.IWukongConsoleApi#-addcommandstring-consolecommand-funcienumerablestring)
  的一个重载，使其能够动态提供命令参数提示。
* `IWukongConsoleApi.AddCommand` 现在在被调用时对命令名称进行验证，而不仅仅在命令被使用时才进行验证。

### 错误修复

* 修复了一个错误：生成的敌人有时会将它们的队伍设为 `2`（默认的敌人队伍），而不是所选队伍，导致它们对玩家产生敌意。
* 修复了在角色或怪物上设置 `.Location` 或 `.Rotation` 时不会生效的问题。
* 执行命令不再导致控制台失去焦点并关闭。请改用 <kbd>F1</kbd> 来关闭命令控制台。
