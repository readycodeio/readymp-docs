我们很高兴宣布 WukongMP SDK 的首个抢先体验版本 - **0.1.0**。

本版本对服务器上模组的存储方式进行了更新，以及开发者定义模组之间依赖关系的方式。

连接到以 SDK 版本 **0.1.0** 构建的服务器需要 ReadyM 启动器的版本 **0.23.1**。

<!-- truncate -->

## 新功能

### 模组版本控制

从版本 **0.1.0** 开始，WukongMP SDK 的所有发布将按照 `MAJOR.MINOR.PATCH` 格式进行版本化。当前版本是
**0.1.0**。

对 SDK 的更新将以新版本发布，并附带各自的文档页面。这使模组开发者能够在其模组的依赖列表中指定 SDK 的特定版本，并在需要时保持与较旧版本的 SDK
的兼容性。

每个版本的下载页面都包含与该版本兼容的服务器二进制包。升级 SDK 时，请确保也将服务器上的二进制包更新为与所使用的 SDK 版本相对应的版本。

### 模组清单

对 `manifest.json`
模组清单文件的支持已添加。现在您可以定义模组元数据，当有人连接到使用您模组的服务器时，这些元数据将在服务器管理门户和启动器中显示。

你还可以指定你模组所依赖的其他模组所需的版本，以使你的模组能够运行。

如需了解更多详细信息，请参阅 [游戏模组清单文件](/wukong-mp/0.1.0/docs/Development/mod-manifest) 的文档。

## 不兼容的变更

- 现在所有模组都需要 `manifest.json` 文件。没有清单的模组将不会被服务器加载。
- 在 **0.23.1** 之前的启动器版本将无法连接到运行 SDK 版本 **0.1.0** 或更高版本的服务器。

## 接下来是什么？

我们目前正在努力将 **PvP模式** 引入到自托管服务器上，并且添加 **服务器端模组支持**。请在接下来的几周内关注更多更新！
