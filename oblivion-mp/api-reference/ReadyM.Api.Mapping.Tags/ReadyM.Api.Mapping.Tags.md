# ReadyM.Api.Mapping.Tags

### Interfaces

 [IServerAuthoritative](../ReadyM.Api.Mapping.Tags/ReadyM.Api.Mapping.Tags.IServerAuthoritative.md)

Marks a component only the server is allowed to modify.

 [IWorldAuthoritative](../ReadyM.Api.Mapping.Tags/ReadyM.Api.Mapping.Tags.IWorldAuthoritative.md)

Marks a component the server authors on the world entity and projects onto every client, which applies
it to the game. The world entity has no client owner, so it is not gated on ownership.
