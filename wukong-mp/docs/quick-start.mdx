# Quick Start

Get a WukongMP server running in under 5 minutes.

## 1. Download the server

<Tabs groupId="os">
<TabItem value="windows" label="Windows">

[⬇ Download for Windows (x64, v0.2.3)](https://readymstorage.blob.core.windows.net/wukong-server-releases/wukong-server-win64-0.2.3.zip)

</TabItem>
<TabItem value="linux" label="Linux">

[⬇ Download for Linux (x64, v0.2.3)](https://readymstorage.blob.core.windows.net/wukong-server-releases/wukong-server-linux64-0.2.3.zip)

</TabItem>
<TabItem value="docker" label="Docker">

```shell
docker pull ghcr.io/readycodeio/wukongmp-server:0.2.3
```

</TabItem>
</Tabs>

## 2. Extract and configure

<Tabs groupId="os">
<TabItem value="windows" label="Windows">

Extract the `.zip` to a folder of your choice. The server is self-contained — no installer needed.

To change the port (default: `9050`), open `config.json` and edit `Server:Port`.

</TabItem>
<TabItem value="linux" label="Linux">

Extract the `.zip` to a folder of your choice. The server is self-contained — no installer needed.

To change the port (default: `9050`), open `config.json` and edit `Server:Port`.

</TabItem>
<TabItem value="docker" label="Docker">

:::important
The image ships **without mods**. Before starting the container, download the binary package and copy `WukongMp.Sdk` and your chosen game mode mod (`WukongMp.PvP` or `WukongMp.Coop`) into your local `./mods/` folder.
:::

Port configuration is handled by remapping the container ports — see step 3.

</TabItem>
</Tabs>

## 3. Start the server

<Tabs groupId="os">
<TabItem value="windows" label="Windows">

Double-click `server.exe`, or run it from a terminal:

```shell
.\server.exe
```

</TabItem>
<TabItem value="linux" label="Linux">

```shell
chmod +x server && ./server
```

</TabItem>
<TabItem value="docker" label="Docker">

```shell
docker run \
    -p 9050:9050/udp -p 9050:9050/tcp \
    -v ./data:/app/data \
    -v ./mods:/app/mods \
    -v ./saves:/app/saves \
    --name wukongmp-server \
    ghcr.io/readycodeio/wukongmp-server:0.2.3
```

Or with Docker Compose:

```yaml title="docker-compose.yml"
services:
  server:
    image: ghcr.io/readycodeio/wukongmp-server:0.2.3
    container_name: wukongmp-server
    restart: unless-stopped
    ports:
      - "9050:9050/tcp"
      - "9050:9050/udp"
    volumes:
      - ./data:/app/data
      - ./mods:/app/mods
      - ./saves:/app/saves
```

</TabItem>
</Tabs>

## 4. Open the admin panel

Once the server is running, open your browser and go to:

```
http://localhost:9050
```

From here you can manage players, configure mods, and monitor your server in real time.

---

🎉 **You're live!** Share your IP and port `:9050` with players — they'll need the ReadyM Launcher installed to connect.
