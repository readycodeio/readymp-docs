### <a id="ReadyM_SDK_Attributes_ExtendsAttribute__ctor_System_Type_System_String_"></a> ExtendsAttribute\(Type, string\)

Adds this mixin to every entity created as the named archetype.

```csharp
public ExtendsAttribute(Type archetype, string prefix = "")
```

#### Parameters

`archetype` [Type](https://learn.microsoft.com/dotnet/api/system.type)

The archetype to add this mixin to.

`prefix` [string](https://learn.microsoft.com/dotnet/api/system.string)

Put in front of each member this mixin adds to the archetype, for a name that would otherwise
read oddly or clash with another mod's. <code>Local</code> turns <code>Stamina</code> into
<code>LocalStamina</code>.
