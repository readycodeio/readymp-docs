# ReadyM.SDK.Server.Seeding

### Interfaces

 [IAreaSeeder](../ReadyM.SDK.Server.Seeding/ReadyM.SDK.Server.Seeding.IAreaSeeder.md)

Fills a new area. Declare it on a <code>[Service]</code>; the server calls it once, when the area is created rather
than loaded from the save.

than loaded from the save.

 [IWorldSeeder](../ReadyM.SDK.Server.Seeding/ReadyM.SDK.Server.Seeding.IWorldSeeder.md)
