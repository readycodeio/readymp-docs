`1.2.0` is out. Everyone on a server now shares one clock, so you are all in the same hour of the same day. Your level and your skills are saved properly. Poison stays on the weapon you put it on. And bans, kicks and whitelists now hold in cases where they used to leak.

Mods need rebuilding against the new SDK. [For modders](/releases/oblivionmp-sdk-120#for-modders) has the list.

<!-- truncate -->

## For players

* **One clock for the server.** The server keeps the time of day and the date, and your game follows it. No more walking through a door into a different hour.
* **Waiting and sleeping are off.** The `T` key does nothing, and a bed only opens the level-up menu when you have a level-up ready. One player's nap would be everyone's six hours, so it is the server's call now. Server owners can switch it back on.
* **Your level and skills are saved.** Logging out no longer costs you the progress you made since your last level-up.
* **Spell and potion bonuses wear off.** Quitting while a fortify effect was running used to make it part of your character forever.
* **Poison stays on the weapon.** It used to follow whatever you had equipped, so it got lost when you traded, stored or dropped a poisoned blade. Poison a second weapon and both stay poisoned.
* **A banned or kicked player stays out.** The same for whitelists. There were a handful of ways to slip through, and they are closed.
* **One account, one PC at a time.** A second machine can no longer take over an account that is already playing.
* **Dropped connections keep retrying.** The game used to try once and give up. It now keeps trying until it is back in, unless you quit or the server gives a reason no retry will fix, such as a kick or a ban.
* **Fixed:** NPCs firing one arrow at a time instead of the whole stack, rings stuck on an NPC's left hand, loading screens showing the wrong player, corpses still swinging weapons, summons left behind after a disconnect or a reload, and `Rebirth` needing a quicksave to work.

Nothing to install. The launcher updates your game when you join a server that has moved to `1.2.0`. Until a server updates, you stay on `1.1.1` there.

## For server owners

Download `1.2.0` for Windows or Linux from the [Installation](/oblivion-mp/docs/Server/installation) page.

Stop the old server, then copy the `saves`, `data` and `branding` folders, `config.json` and your own mods into the new package, along with any config file you edited in a mod the package ships. Existing saves load as they are, skills and all. Rebuild your own mods first: a mod built against `1.1.0` or `1.1.1` will not load.

New setting:

* `AllowTimeSkip` in `mods/OblivionMp.Sdk/server/config.json` turns waiting and sleeping back on. Your players also need `HideWaitMenu` off in `mods/OblivionMp.Sdk/client/config.json`, which the server hands out, so you edit that one too. Remember that a skip moves the clock for everyone on the server.

## For modders

The SDK packages are `1.2.0`. Bump them and your manifest's `minimumVersion`, then work through this:

| Was, in `1.1.1` | Now, in `1.2.0` |
|---|---|
| `SkillAttributes`, read and write | `SkillAttributes` is read-only and holds the effective values, base plus running effects. Write `BaseSkillAttributes` instead. |
| The `Time` mixin, on `Area`, owner-based | Renamed `GameTime`, because `Time` inside a service is the service's update clock. It is on `World` now and server-authoritative, so a client cannot write it. |
| `Time.GameHour`, a float from 0 to 24 | `GameTime.TimeOfDay`, a read-only `TimeSpan`, and `GameTime.TimeOfDayMinutes`, a float |
| `Time.GameDaysPassed`, a float | `GameTime.GameDay`, a `uint` |
| `Time.TimeScale` | `GameTime.Timescale`, lower-case `s` |
| `SessionClock` | `WorldClock`, in `OblivionMP.SDK.Serverside.Systems`. `NowGameHours()` works the same and is no longer per area. |
| `TimeChangeEvent` | `TimeSkipRequestEvent`, raised when a player confirms the wait menu |
| `Equipment.CurrentPoison`, one per character | `ItemExtraData.Poison`, one per item, on inventory entries and dropped items |

New alongside those: `LevelMixin.LevelExperience` for progress towards the next level, `GameTime.Date` and the `OblivionMP.SDK.Common.Calendar` namespace for the Tamrielic calendar, and `ServerConfig` and `ClientConfig` for the SDK's own settings.

`WorldClock` is a service like any other, so a mod that wants to run time its own way disables it through `IServices` and advances `GameTime.GameDay` and `GameTime.TimeOfDayMinutes` itself. Time skipping is the same: handle `TimeSkipRequestEvent` and do what you like with it. Watch out for the double skip, though. The SDK applies the skip itself when `AllowTimeSkip` is on, so leave it off if your own handler already does it. [Time, weather and session](/oblivion-mp/docs/Modding/Game/time-weather-session) covers all of this.
