`1.2.0` is out, and the biggest change is that the server keeps the time. Everyone on it shares one clock and one calendar, so you are all in the same hour of the same day. Bans, kicks and whitelists hold in cases where they used to leak. Your level and your skills survive a logout, and poison stays on the weapon you put it on.

There is nothing to install if you play. The launcher updates your game when you join a server that has moved to `1.2.0`, and until a server updates you stay on `1.1.1` there.

Mods need rebuilding, and most need editing. [Upgrading](/releases/oblivionmp-sdk-120#upgrading) has the list.

## What's new

### One clock for the server

The server keeps the time of day and the date, and every player's game follows it. No more walking through a door into a different hour.

Waiting and sleeping are off because of it, since one player's six-hour nap would be everyone's six hours. The wait key, `T` by default, does nothing, and a bed opens the level-up menu when you have a level-up ready and does nothing otherwise. A server owner who wants them back turns `AllowTimeSkip` on in `mods/OblivionMp.Sdk/server/config.json` and turns `HideWaitMenu` off in `mods/OblivionMp.Sdk/client/config.json`, which the server hands out to players.

### Connections, bans and whitelists

A banned or kicked player stays out, and so does one who is not on the whitelist. There were a handful of ways to slip through and they are closed. One account also plays from one PC at a time: a second machine no longer takes over a session that is already running.

A dropped connection keeps retrying now, where the game used to try once and give up. It stops when you quit, or when the server gives a reason no retry will fix, such as a kick or a ban.

## Fixed

* Logging out no longer costs you the level and skill progress you made since your last level-up.
* Spell and potion bonuses wear off. Quitting while a fortify effect was running used to make it part of your character forever.
* Poison stays on the weapon instead of following whatever you have equipped, so it is no longer lost when you trade, store or drop a poisoned blade. Poison a second weapon and both stay poisoned.
* NPCs fire the whole stack of arrows instead of one at a time.
* Rings no longer stick on an NPC's left hand.
* A loading screen no longer shows the wrong player.
* Corpses stop swinging their weapons.
* Summons no longer stay behind after a disconnect or a reload.
* `Rebirth` no longer needs a quicksave to work.

## Upgrading {#upgrading}

### Your mods

Bump the SDK packages and your manifest's `minimumVersion` to `1.2.0`, then work through this:

| Was, in `1.1.1` | Now, in `1.2.0` |
|---|---|
| `SkillAttributes`, read and write | `SkillAttributes` is read-only and holds the effective values, base plus running effects. Write `BaseSkillAttributes` instead. |
| The `Time` mixin, on `Area`, owner-based | Renamed `GameTime`, because `Time` inside a service is the service's update clock. It is on `World` now and server-authoritative, so a client cannot write it. |
| `Time.GameHour`, a float from 0 to 24 | `GameTime.TimeOfDay`, a read-only `TimeSpan`, and `GameTime.TimeOfDayMinutes`, a float |
| `Time.GameDaysPassed`, a float | `GameTime.GameDay`, a `uint` |
| `Time.TimeScale` | `GameTime.Timescale`, lower-case `s` |
| `SessionClock` | `WorldClock`, in `OblivionMP.SDK.Serverside.Systems`. `NowGameHours()` works the same and is no longer per area. |
| `TimeChangeEvent` | `TimeSkipRequestEvent`, raised when a player confirms the wait menu |
| `Equipment.CurrentPoison`, one per character | `ItemExtraData.Poison`, one per item, on inventory entries and dropped items |

New alongside those: `LevelMixin.LevelExperience` for progress towards the next level, `GameTime.Date` and the `OblivionMP.SDK.Common.Calendar` namespace for the Tamrielic calendar, and `ServerConfig` and `ClientConfig` for the SDK's own settings.

`WorldClock` is a service like any other, so a mod that wants to run time its own way disables it through `IServices` and advances `GameTime` itself. Time skipping is the same: handle `TimeSkipRequestEvent` and do what you like with it. Watch out for the double skip, though. The SDK applies the skip itself when `AllowTimeSkip` is on, so leave it off if your own handler already does it. [Time, weather and session](/oblivion-mp/docs/Modding/Game/time-weather-session) covers all of this.

Recompile either way. A mod built against `1.1.0` or `1.1.1` will not load on `1.2.0`, even if nothing above applies to it.

### Your server

1. Recompile your mods against the 1.2.0 SDK.
2. Download the 1.2.0 server package for Windows or Linux from [Installation](/oblivion-mp/docs/Server/installation).
3. Stop the old server.
4. Copy the `saves` folder, the `data` folder, the `branding` folder and the server's own `config.json` from the old server folder into the new one.
5. Copy your own mods into the new `mods` folder, and with them any config file you edited in a mod the package ships.
6. Start the new server.

Existing saves load as they are, skills and all.
